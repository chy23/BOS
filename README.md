# BOS - 行為觀察速記與多師協同分析系統 (Behavior Observation System)

> **系統架構與領域設計 (System Architect & Designer)**：**Chiahua (`chy23`)**  
> **版本**：`v3.1.0 PRO`（跨裝置自適應：手機雙欄拇指速記 ／ 平板與電腦 3×3 九宮格 ／ 進階模式臨床鑑別映射）

一套專為課堂觀察、特教輔導、常規追蹤與臨床評估設計的**手機、平板與電腦全自適應觸控速記與多師協同系統**。  
支援**「多位科任老師與導師共同記錄同一份個案資料」**、**「3 碼英數隨機代號（去識別化）」**、**「個案管理與刪除」**、**「A-B-C 行為脈絡注記」**、**「正向良好行為 ★ 加分」**、**「ADHD 三大核心面向分析」**，並可**「一鍵匯出 Word 報表 (.doc)」**與**「無縫同步至個人 Google 試算表」**。

---

## 🌟 核心特色

1. **多師跨載具協同記錄（科任老師 ＋ 導師共同記錄同一天）**：
   - 頂部支援切換老師身分（導師、英文科任、自然科任、體育科任、音樂科任、特教老師、自訂職稱）。
   - **節次級智慧合併（Granular Merge Upsert）**：科任老師點擊「🚀 僅儲存/同步本節」，只會寫入該堂課的觀察紀錄，絕不會覆蓋其他科任老師或導師所填寫的節次！
   - 提供「🔄 載入最新」按鈕，隨時拉取其他老師剛完成的最新課堂紀錄。
2. **個案管理與安全刪除功能**：
   - 點擊「👥 個案管理」可查看所有建立的個案清單、觀察天數、行為次數。
   - 可在平板本地填寫備忘暱稱（如「個案A」），僅存本地不外傳。
   - 支援安全刪除個案（含二次防呆確認，並可選擇是否連帶清除歷史觀察記錄）。
3. **特教與 ADHD 臨床指南落地（依據參考指引深度設計）**：
   - **A-B-C 行為脈絡注記**：
     - **A 前事觸發 (Antecedent)**：快選標籤（教師講課、獨立書寫、分組活動、轉銜鐘響、同儕攀談、疲憊飢餓等）。
     - **B 核心行為 (Behavior)**：還原紙本 6 大代號（○ 玩文具、+ 放空、↑ 找東西、～ 扭動、× 干擾、！ 搶話）。
     - **C 後果反應 (Consequence)**：快選標籤（口頭提醒、手勢示意、肢體引導、抽離至冷靜角、同儕起鬨、刻意忽略等）。
   - **正向良好行為 ★ 加分**：特教核心原則「不只挑毛病，更捕捉優點」，點擊加分卡記錄良好專注或適應行為，作為代幣增強制依據。
   - **ADHD 三大面向自動歸納**：統計頁自動將行為聚合為「注意力不足 (Inattention)」、「過動現象 (Hyperactivity)」、「衝動控制 (Impulsivity)」，便於兒童心智科醫師門診與 IEP 會議參考。
4. **根據作息課表自動跳轉堂課（即時自動跟隨）**：
   - 內建精準學校作息排程表，網站載入或進入速記時**自動根據系統當前時間跳到該堂課**，節次標籤顯示綠色呼吸燈 `● 現在課堂`：
     - `早自習 (08:00~08:35)`：晨間活動與導師時間
     - `第一節 (08:40~09:20)`：第 1 節課 (下課 09:20~09:30)
     - `第二節 (09:30~10:10)`：第 2 節課 (大下課 10:10~10:30)
     - `第三節 (10:30~11:10)`：第 3 節課 (下課 11:10~11:20)
     - `第四節 (11:20~12:00)`：第 4 節課
     - `中午 (12:00~13:10)`：午餐時間 (12:00~12:40) / 午休 (12:40~13:10)
     - `第五節 (13:20~14:00)`：第 5 節課 (下課 14:00~14:10)
     - `第六節 (14:10~14:50)`：第 6 節課 (下課 14:50~15:10)
     - `第七節 (15:10~15:50)`：第 7 節課 / 放學 (15:50~16:00)
   - 提供「⏰ 自動依課表跳轉」開關與「⚡️ 跳至現在課堂」一鍵快捷按鈕。
5. **雲端設計頁整合與 100% 資安無風險保證**：
   - 在「⚙️ 雲端設定」頁面直接提供後端 `Code.gs` 完整程式碼與一鍵複製按鈕。
   - 通過資安無風險檢驗：100% 資料存在您個人 Google Drive，全程 HTTPS 加密，純 3 碼亂碼去識別化。
6. **雙向匯出與儲存**：
   - **Word 報表匯出**：一鍵下載格式整齊的 Word 文件，包含完整表格、情境脈絡與客觀分析結論。
   - **Google 生態系整合**：支援離線暫存，並透過 Google Apps Script 將資料自動同步到個人的 Google 試算表。
7. **系統更新紀錄設置 (Release Notes & Changelog)**：
   - 頂部導航列、頁尾與「⚙️ 雲端設定」頁面內建完整的「✨ 更新紀錄」設置與彈窗。
   - 詳細記錄自 v1.0.0 紙本數位化、v1.5.0 Google 試算表直連、v2.0.0 實體作息課表連動、v2.5.0 資安加固，至 v3.0.0 進階臨床量化模式的全版本演進歷程。
8. **🔬 進階臨床行為量化與疾病鑑別映射模式 (v3.0.0 PRO)**：
   - **雙模式共存連動**：保留原始紙本 7 代碼「基礎速記模式」，並新增符合 `ClassroomBehaviorRecord` (JSON Schema Draft 2020-12) 的「進階臨床模式」，儲存時可自動同步累加至基礎速記表。
   - **五大結構化量化維度**：
     1. `context`（基本情境：1-8 節次、10 大科目、6 種教學活動型態、物理環境備註）。
     2. `antecedent`（前因與誘發因子分類與 9 項具體描述，自動推論潛在病因機制）。
     3. `behavior`（6 大向度、17 項行為代碼 `OFF`/`FD`/`TI`/`WM`/`LM`/`OOS`/`MV`/`NV`/`CO`/`TB`/`IN`/`RU`/`FR`/`RSD`/`TIC_M`/`TIC_V`/`HF`，含擴充屬性 `related_conditions` 9 大臨床障礙標籤）。
     4. `metrics`（發生頻率 `frequency`、持續時間 `duration_minutes` 內建課堂即時碼錶、干擾強度 `intensity` 1~3 級）。
     5. `intervention` & `qualitative_notes`（7 種大人立即處置策略、4 級介入反應成效與質性文字觀察）。
   - **臨床診斷與鑑別疾病映射引擎**：即時提示每項行為之「首要指向疾病 (Primary)」、「鑑別診斷與常見共病 (Differential)」與「臨床鑑別關鍵點」，並支援一鍵匯出進階臨床鑑別 Word 報告 (`.doc`) 與標準 JSON (`.json`)。

## 🚀 如何在 GitHub 啟用網站 (GitHub Pages)

本專案為純前端結構，可直接免費託管於 GitHub Pages：

1. 登入 GitHub 並進入此 Repository：[https://github.com/chy23/BOS](https://github.com/chy23/BOS)。
2. 點擊頂部的 **「Settings (設定)」**。
3. 在左側選單中點選 **「Pages」**。
4. 在 **「Build and deployment」** 區塊：
   * **Source** 選擇：`Deploy from a branch`。
   * **Branch** 選擇：`main` 分支，資料夾選擇 `/ (root)`。
5. 點擊 **「Save (儲存)」**。
6. 等候約 1~2 分鐘，上方即會出現您的專屬網站網址（例如：`https://chy23.github.io/BOS/`）。
