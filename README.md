# BOS - 行為觀察速記與分析系統 (Behavior Observation System)

一套專為課堂觀察、特教輔導與常規追蹤設計的**平板觸控速記系統**。  
支援**「3 碼英數隨機個案代號（嚴格去識別化）」**、**「課堂情境脈絡即時注記」**、**「歷史紀錄回溯更新」**、**「當日/當週/長期時段分佈熱區分析」**，並可**「一鍵匯出 Word 報表 (.doc)」**與**「無縫同步至個人 Google 試算表」**。

---

## 🌟 核心特色

1. **平板速記最佳化（課堂不中斷教學）**：
   - 還原附檔紙本 6 大行為代號（`○` `+` `↑` `～` `×` `！` `V`），設計超大觸控按鈕，點擊立即記次。
   - 9 個節次快速切換（早自習、第一節～第四節、中午、第五節～第七節）。
2. **根據作息課表自動跳轉堂課（即時自動跟隨）**：
   - 內建精準學校作息排程表，網站載入或進入速記時**自動根據系統當前時間跳到該堂課**，節次標籤顯示綠色呼吸燈 `● 現在課堂`：
     - `早自習 (08:00~08:35)`：晨間活動與導師時間
     - `第一節 (08:40~09:20)`：第 1 節課 (下課 09:20~09:30)
     - `第二節 (09:30~10:10)`：第 2 節課 (大下課 10:10~10:30)
     - `第三節 (10:30~11:10)`：第 3 節課 (下課 11:10~11:20)
     - `第四節 (11:20~12:00)`：第 4 節課
     - `中午 (12:00~13:10)`：午餐時間 (12:00~12:40) / 午休 (12:40~13:10)
     - `第五節 (13:20~14:00)`：第 5 節課 (下課 14:00~14:10)
     - `第六節 (14:10~14:50)`：第 6 節課 (下課 14:50~15:10)
     - `第七節 (15:10~15:50)`：第 7 節課 / 放學 (15:50~16:00)
   - 提供「⏰ 自動依課表跳轉」開關與「⚡️ 跳至現在課堂」一鍵快捷按鈕，課堂切換免手動。
3. **個案 3 碼英數亂碼管理**：
   - 系統一鍵自動生成 3 碼英數亂碼（如 `B7K`、`M9X`），支援多位個案長期追蹤，同時達到嚴格的個人資料去識別化防護。
3. **情境脈絡注記（ABC 行為前事與課堂活動）**：
   - 內建 10 種課堂情境快捷標籤（如：教師單向講課、學生個別書寫、分組討論、下課轉銜等），支援平板手寫或語音轉文字備註。
4. **既有紀錄回溯與更新（Update/Upsert）**：
   - 點選任何歷史日期即可自動載入舊有資料進行「編輯更新」，不會重複插入冗餘資料。
5. **長期累積與時段熱區分析（Heatmap）**：
   - 提供當日排行、當週趨勢曲線，以及 **時段 × 行為代號 交叉分佈熱區矩陣**，清楚掌握行為集中在何時、哪項行為最多。
6. **雙向匯出與儲存**：
   - **Word 報表匯出**：一鍵下載格式整齊的 Word 文件，包含完整表格、情境脈絡與客觀分析結論。
   - **Google 生態系整合**：支援離線暫存，並透過 Google Apps Script 將資料自動同步到個人的 Google 試算表。

## 🚀 如何在 GitHub 啟用網站 (GitHub Pages)

本專案為純前端結構，可直接免費託管於 GitHub Pages：

1. 登入 GitHub 並進入此 Repository：[https://github.com/chy23/BOS](https://github.com/chy23/BOS)。
2. 點擊頂部的 **「Settings (設定)」**。
3. 在左側選單中點選 **「Pages」**。
4. 在 **「Build and deployment」** 區塊：
   * **Source** 選擇：`Deploy from a branch`。
   * **Branch** 選擇：`main` 分支，資料夾選擇 `/ (root)`。
5. 點擊 **「Save (儲存)」**。
6. 等候約 1~2 分鐘，上方即會出現您的專屬網站網址（例如：`https://chy23.github.io/BOS/`）。

## 📱 平板操作技巧（全螢幕 App 模式）

* **iPad (Safari)**：
  開啟網站 ➔ 點擊右上角「分享」圖示 ➔ 選擇 **「加入主畫面」**。之後點擊桌面圖示即可全螢幕使用，無瀏覽器網址列干擾。
* **Android 平板 (Chrome)**：
  開啟網站 ➔ 點擊右上角選單（三個點） ➔ 選擇 **「加到主螢幕」**。
