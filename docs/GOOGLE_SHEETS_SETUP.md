# Google 試算表與生態系整合指南 (5分鐘快速架設)

本系統支援將平板上的所有觀察紀錄即時同步到您個人的 Google 雲端硬碟（Google Sheets）。

---

## 一、 建立 Google 試算表與設定後台

1. 打開 [Google 雲端硬碟](https://drive.google.com/)，點擊「新增」 ➔ **「Google 試算表」**。
2. 將試算表命名為：`BOS_學生行為觀察資料庫`。
3. 點選上方選單的 **「擴充功能」 ➔ 「Apps Script」**。
4. 將專案中的 `google-apps-script/Code.gs` 檔案內容完整複製，覆蓋貼上到 Apps Script 編輯器中。
5. 點擊上方的 **「儲存」圖示**（或按 Ctrl+S / Cmd+S）。

---

## 二、 部署為 Web 應用程式 (Web App)

1. 點擊 Apps Script 視窗右上角的 **「部署」 ➔ 「新建部署」**。
2. 點擊齒輪圖示，選擇類型為 **「網頁應用程式 (Web App)」**。
3. 設定參數：
   * **說明**：`BOS API v1`
   * **執行身分**：`我 (您的 Google 帳號)`
   * **誰可以存取**：**`所有人 (Anyone)`** *(說明：因平板前端網頁送出資料時不需要登入 Google 帳號，設定為所有人可確保平板直接寫入)*
4. 點擊 **「部署」**，並在跳出的視窗中點擊 **「核准存取權 (Review Permissions)」** ➔ 選擇您的帳號 ➔ 點選「進階」 ➔ 點選「前往...（安全）」。
5. 複製生成的 **「網頁應用程式網址 (Web App URL)」**（網址結尾通常為 `/exec`）。

---

## 三、 在 BOS 平板系統完成綁定

1. 開啟 BOS 系統網頁，切換到 **「⚙️ 雲端設定」** 頁籤。
2. 將剛才複製的 Web App 網址貼入輸入框中。
3. 點擊 **「儲存網址」**，接著點擊 **「連線測試」**。
4. 當顯示 `✅ 連線成功`，即代表綁定完成！

---

## 四、 試算表自動生成的資料庫結構

當您在平板點擊「儲存/更新此日完整紀錄」時，Google 試算表會自動建立並維護以下工作表：

1. **`行為原始紀錄`**：
   * 欄位：`更新時間戳記`、`個案代號 (3碼)`、`日期`、`用藥時間`、`身體不適紀錄`、`節次`、`行為代號`、`行為名稱`、`次數`、`情境標籤`、`情境細節備註`。
   * 特色：支援 **Upsert（自動覆蓋更新）**，修改同日同個案資料不會重複塞滿。
2. **`個案代號清單`**：
   * 自動維護所有匿名個案代號與建立時間。
