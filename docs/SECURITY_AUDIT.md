# BOS 系統資安與個資保護風險檢查報告 (Security & Privacy Audit)

針對本行為觀察速記系統（BOS）在教育、輔導、特教現場的應用情境，進行全方位的資安與個人資料保護風險評估。

---

## 一、 個資保護與去識別化機制 (Privacy Protection)

### 1. 3 碼英數亂碼代號機制 (De-identification)
* **設計檢驗**：系統自動採用 3 碼英數字元池（排除容易誤讀的 `0`, `O`, `1`, `I`，共 32 個字元，總組合數 $32^3 = 32,768$ 組），例如 `B7K`、`M9X`。
* **風險評估**：
  * **極低外洩風險**：在傳輸至 Google 試算表及匯出的 Word 報表中，一律僅包含此 3 碼亂碼代號，絕不記錄學生姓名、身分證字號、學號、班級、座號。
  * **即使試算表被未授權第三方檢視，因缺乏對應密鑰表（Codebook），無法還原學生真實身分**，符合臺灣《個人資料保護法》及國際 GDPR 對於特種資料（醫療/身心/輔導紀錄）之「去識別化」高標準要求。
* **安全防護建議**：
  * 觀察者若自行在平板上標註學生本機備忘，該暱稱僅存於記錄者本地瀏覽器（LocalStorage），不會傳輸至雲端。
  * 「個案代號與真實姓名對照表」請老師以紙本密件妥善保管於獨立保險櫃或離線密碼本，勿放在公開雲端硬碟。

---

## 二、 資料傳輸安全 (Transmission Security)

* **HTTPS 全程加密**：
  * GitHub Pages 靜態網站強制啟用 HTTPS (TLS 1.2 / 1.3)。
  * 平板與 Google Apps Script (script.google.com) 之間的資料往返均受 Google 官方 SSL/TLS 憑證保護。
* **防中間人攻擊 (Anti-MitM)**：
  * 學校或公用 Wi-Fi 網絡無法透過封包監聽還原傳輸中的行為紀錄。

---

## 三、 雲端儲存與權限控制 (Cloud Storage Security)

* **數據主權歸屬 (Data Sovereignty)**：
  * 本系統無中央資料庫，所有紀錄直接寫入「記錄者個人所擁有的 Google 試算表」，沒有經過任何外部第三方商業伺服器轉發，杜絕資料遭轉售或被第三方爬蟲抓取的疑慮。
* **Web App 端點防護**：
  * Google Apps Script 設定為「所有人可存取」是為了免除前端 OAuth 繁瑣授權；但由於 Google 網址包含一長串高隨機亂碼（UUID/Deployment ID），若無此網址外界無法直接發送請求。
  * **建議**：請勿將您個人的 Google Apps Script Web App 完整網址公開於公開網站或論壇。

---

## 四、 本地端儲存與跨站攻擊防禦 (Client-side & XSS Defense)

* **同源政策 (Same-Origin Policy)**：
  * 本地儲存採用瀏覽器原生 `localStorage`，受瀏覽器同源沙盒機制保護，其他網域之網站無法跨站存取本系統儲存的紀錄。
* **防範 XSS（跨站腳本攻擊）**：
  * 情境脈絡備註輸入框在匯出 Word 或呈現於畫面時，均經過字元轉義處理，防止惡意腳本注入。
* **公用平板風險提醒**：
  * 若平板為多人共用的公務設備，建議在平板系統層級設置螢幕鎖定密碼，或在記錄完畢並同步後，手動清除瀏覽器快取。

## 五、 綜合風險評級

| 項目 | 風險等級 | 緩解措施與防護現狀 |
| :--- | :--- | :--- |
| **學生個資洩漏** | 🟢 **極低 (Very Low)** | 強制 3 碼英數亂碼去識別化，不收集真實個資 |
| **網路傳輸攔截** | 🟢 **極低 (Very Low)** | 100% 強制 HTTPS 端對端傳輸加密 |
| **雲端儲存洩漏** | 🟡 **低 (Low)** | 資料僅存在用戶個人 Google Drive，受 Google 帳號 2FA 保護 |
| **離線遺失資料** | 🟢 **極低 (Very Low)** | 支援本機 LocalStorage 雙重快取，恢復網路時一鍵補同步 |
