串接您學校或個人的 Google Apps Script Web App，所有科任老師可共同協同寫入同一試算表。

        


        

          
          

            
            
            
          

          

        


        
        

          

            🛡️資安與個資安全無風險驗證通過 (Security & Privacy Verified)
          

          
    
            
  • 100% 原始資料主權：紀錄直通您個人的 Google 試算表，不經過任何第三方雲端或商業伺服器。
    • 
            
  • 嚴格去識別化：傳輸中一律僅使用 3 碼亂碼代號，絕不記錄學生真名、身分證號或學號。
    • 
            
  • 全程 HTTPS 加密：採用 Google TLS 1.3 高強度傳輸通道，杜絕校園 Wi-Fi 封包側錄。
    • 
            
  • 試算表防公式注入 (CWE-1236)：自動轉義 =+ - @ 字元，封堵試算表惡意巨集攻擊。
    • 
            
  • 報表防腳本注入 (XSS)：匯出 Word 之情境備註文字 100% 完成 HTML 實體轉義。

              v3.0.0 當前最新版 (PRO)
            
            2026-11-11
          

          
進階臨床行為量化模式 · ClassroomBehaviorRecord Schema · 疾病鑑別診斷映射

          
    
            
  • 雙模式無縫共存：保留原始紙本 7 代碼「基礎速記模式」，並新增「🔬 進階臨床量化模式」，兩者支援自動同步累加。
    • 
            
  • 標準化資料結構 (JSON Schema Draft 2020-12)：完整實作 ClassroomBehaviorRecord 結構（record_id、student_id、timestamp、context、antecedent、behavior、metrics、intervention、qualitative_notes）與即時 Schema 驗證器。
    • 
            
  • 6 大向度 17 項具體行為代碼：涵蓋 OFF、FD、TI、WM、LM、OOS、MV、NV、CO、TB、IN、RU、FR、RSD、TIC_M、TIC_V、HF。
    • 
            
  • 臨床診斷與鑑別疾病映射引擎：每項行為與誘發因子均即時對映「首要指向疾病 (Primary)」、「鑑別診斷與共病 (Differential)」、「臨床鑑別關鍵點」及擴充屬性 related_conditions（9 大臨床障礙標籤）。
    • 
            
  • 行為量化指標與課堂碼錶：內建持續時間（duration_minutes）即時碼錶、干擾強度 1~3 級評估，以及介入處置（strategy）與成效（outcome）有效率統計。
    • 
            
  • 多元專業匯出：支援匯出「進階臨床鑑別 Word 報告 (.doc)」與標準「ClassroomBehaviorRecord (.json)」，並同步寫入 Google 試算表。

              v2.5.0
            
            2026-11-11
          

          
資安與個資全面防護 · Apple HIG 觸控升級 · 文字化熱區 · 多師協同

          
    
            
  • 資安防護加固：完成資安稽核，後端 Google Apps Script 實裝 CWE-1236 試算表公式注入防禦（sanitizeCell）與個案代碼格式嚴格驗證；前端 Word 匯出加入 HTML 實體轉義（防 XSS）。
    • 
            
  • Apple HIG / Apple Design 觸控體驗：卡片全空白區域支援點選即記次（+1），符合 44×44pt 最小觸控目標規範與彈簧按壓反饋。
    • 
            
  • 視覺簡化與微動態圖示：依需求移除冗餘之方框小圖示，右下角優雅保留半透明 60fps CSS 仿 GIF 微動畫（鉛筆搖動、發呆雲朵、搜尋放大鏡、擺腿、對話波紋、大聲公）。
    • 
            
  • 熱區與報表繁中文字化：統計矩陣與 Word 報表全面採用「玩文具雜物、放空發呆、尋找遺失物、扭動身體、干擾他人、未舉手搶話、正向好行為」等完整中文語意，不再顯示單一符號。
    • 
            
  • A-B-C 行為脈絡與 ADHD 三面向：整合前置情境（A）、具體行為（B）、後果反饋（C）與正向行為統計，對齊特教臨床診斷維度。
    • 
            
  • 多師協同機制：支援不同科任老師身份標記，細粒度節次級（Period-level）合併更新，防止互相覆蓋。
    • 
            
  • 個案刪除功能：支援完整刪除已結案之代號，並提供一鍵抹除本機與雲端歷史紀錄之選項。
